# Mijn Persoonlijke Portfolio

Een responsive portfolio-website gebouwd met **HTML, CSS en JavaScript**.
Schoolproject MBO IT – Week 4 (IT Basic). Hier laat ik zien wie ik ben,
welke projecten ik heb gemaakt en hoe je contact met mij opneemt.


## Functionaliteiten

- Responsive navigatie met hamburger-menu op mobiel
- Hero-sectie met typewriter-effect (`Webdeveloper / Student IT / software develepor`)
- Secties: Home, Over mij, Projecten, Contact
- Projectenoverzicht met 3 voorbeeldkaarten in een responsive grid
- Contactformulier met JavaScript-validatie (lege velden + e-mailcheck)
- Footer met automatisch jaar en back-to-top knop


## Aan de slag

Vereisten: een browser (Chrome / Edge) en optioneel VS Code met Live Server.

1. Open het project in VS Code.
2. Voeg je foto toe in `images/`, bijvoorbeeld als `images/profielfoto.jpg`.
   De pagina verwijst hier al naar in `index.html`.
3. Open de site:
   - Dubbelklik op `index.html`, of
   - In VS Code: rechtsklik op `index.html` → Open with Live Server.


## Aanpassen naar jezelf

- Open `index.html` en vervang `Ammar` door je eigen naam.
- Vul bij Over mij je opleiding in (bijv. MBO IT Utrecht, leerjaar 1).
- Vervang de 3 voorbeeldprojecten door je eigen projecten.
- Eigen woorden in het typewriter-effect? Pas de `words`-lijst aan in `js/script.js`.
- Kleuren aanpassen? Zoek in `css/style.css` naar `:root` (`--primary`, `--dark`).


## Technologieën

- HTML5 (semantische tags: `header`, `main`, `section`, `footer`)
- CSS3 (Grid, Flexbox, Media Queries, CSS-variabelen)
- JavaScript (DOM, Events, scroll-listener, geen frameworks nodig)
